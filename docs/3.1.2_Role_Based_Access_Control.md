## 1. Ringkasan Implementasi

WBS 3.1.2 mengimplementasikan sistem kontrol akses berbasis peran (*Role-Based Access Control / RBAC*) yang ketat pada sisi backend Express.js. Sistem memastikan setiap rute dan operasi sensitif hanya dapat dieksekusi oleh entitas yang memiliki hak akses (*privilege*) yang sesuai.

### Berkas Terkait:
- Middleware RBAC: [`backend/middleware/authorize.js`](../backend/middleware/authorize.js)
- Middleware Autentikasi: [`backend/middleware/authenticate.js`](../backend/middleware/authenticate.js)
- Skrip Pengujian: [`backend/tests/test_3_1_2_rbac.js`](../backend/tests/test_3_1_2_rbac.js)

## 3. Logika & Mekanisme Middleware RBAC

Implementasi middleware bersifat deklaratif menggunakan fungsi *higher-order* `authorize(...roles)`:

```javascript
// backend/middleware/authorize.js
const authorize = (...roles) => {
  return (req, res, next) => {
    // 1. Cek apakah objek req.user tersedia dari middleware authenticate
    // 2. Cek apakah role pengguna termasuk dalam daftar role yang diizinkan
    if (!req.user || !roles.includes(req.user.role)) {
      return res.status(403).json({
        success: false,
        message: 'Forbidden. You do not have permission to access this resource.'
      });
    }
    // 3. Jika valid, teruskan ke handler controller berikutnya
    next();
  };
};

module.exports = authorize;
```

### Contoh Penerapan Proteksi Rute:

```javascript
// 1. Rute Khusus Penjual (Seller)
router.get('/queue', authenticate, authorize('seller'), sellerQueueController.getQueue);
router.post('/menu', authenticate, authorize('seller'), upload.single('photo'), menuController.addMenu);

// 2. Rute Khusus Administrator (Admin)
router.get('/metrics', authenticate, authorize('admin'), adminController.getMetrics);
router.patch('/applications/umkm/:id/review', authenticate, authorize('admin'), applicationController.reviewUmkm);
router.patch('/users/:id/role', authenticate, authorize('admin'), adminController.updateUserRole);

// 3. Rute Multi-Role
router.post('/orders', authenticate, authorize('buyer'), orderController.checkout);
router.post('/applications/stall', authenticate, authorize('buyer', 'seller'), applicationController.applyStall);
```
